# 三良中古 · 交互展示原型

这是 HTML/CSS/JavaScript 前端演示，不提供真实支付、发货或商品鉴定服务。未提供的商品数据为演示数据，部分视角图为生成演示素材。收藏、地址等状态只保存在访客自己的浏览器中。

## 免费发布到 GitHub Pages

将本目录作为仓库根目录（包括 .github 和 site）。仓库使用 public，默认分支 main。在 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。运行 Deploy Sanliang demo to GitHub Pages 工作流。完成后 GitHub 提供 https://用户名.github.io/仓库名/ 链接。

网页入口在 site/index.html；保留其目录结构。无需安装依赖或构建。网站及源码公开访问。
